# 🎮 Tic-Tac-Toe AI — Minimax & Alpha-Beta Pruning

An intelligent Tic-Tac-Toe game developed using **Python, Pygame, the Minimax algorithm, and Alpha-Beta Pruning**.

This project demonstrates how Artificial Intelligence can make strategic decisions by evaluating possible game states and selecting optimal moves.

Play against an AI opponent or enjoy a classic two-player game!

---

## ✨ Features

- 🤖 **AI Opponent:** Uses Minimax with Alpha-Beta Pruning to select moves.
- 🎯 **Intelligent Decision-Making:** Evaluates possible game outcomes before choosing a move.
- 🖥️ **Graphical User Interface:** Play using an interactive graphical interface.
- 💻 **Text-Based Gameplay:** Run the game directly in your terminal.
- 👥 **Two-Player Mode:** Play against another person.
- 🔄 **Replay Support:** Restart games and continue playing.
- 🧩 **Modular Code:** Separate modules for game logic, interface, controller, and AI.
- 📚 **Educational Project:** Explore fundamental concepts of adversarial search in AI.
